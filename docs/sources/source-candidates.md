# Source Candidates

## Source Strategy

The project keeps a broad source catalog, but the MVP should collect from a smaller priority set.
This keeps the first 2 weeks focused on useful backend signals instead of building a noisy crawler.

Priority levels:

- P1: Use in the 2-week MVP.
- P2: Add after the MVP if RSS/feed integration is easy.
- P3: Keep as a candidate, but filter aggressively or defer.
