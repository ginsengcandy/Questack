|===
|Path|Type|Description

|`+feedCount+`
|`+Number+`
|Number of configured RSS/Atom feeds processed.

|`+fetchedCount+`
|`+Number+`
|Number of items fetched from all feeds.

|`+savedCount+`
|`+Number+`
|Number of newly saved collected items.

|`+skippedDuplicateCount+`
|`+Number+`
|Number of feed items skipped because their canonical URL already exists or is blank.

|`+failedFeedCount+`
|`+Number+`
|Number of feeds that failed while other feeds continued processing.

|`+failedFeeds+`
|`+Array+`
|Failed feed details.

|`+failedFeeds[].feedName+`
|`+String+`
|Configured name of the failed feed.

|`+failedFeeds[].feedUrl+`
|`+String+`
|Configured URL of the failed feed.

|`+failedFeeds[].reason+`
|`+String+`
|Failure reason captured from the feed request or parser.

|===
